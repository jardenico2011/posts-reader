# Posts Reader

A simple Posts Reader application built with React, TypeScript, and Vite.

## Live Website

https://posts-reader-delta.vercel.app

## Features

- View all posts
- View individual post details
- View comments for each post
- Display author avatars
- Loading skeletons
- Error handling
- Custom 404 page
- Light and dark mode

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios
- TanStack Query
- JSONPlaceholder API
- Vercel

## API

https://jsonplaceholder.typicode.com
